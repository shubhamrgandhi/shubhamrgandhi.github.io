# shubhamrgandhi.github.io

Personal academic website of Shubham Gandhi, Ph.D. student at the Language Technologies Institute, Carnegie Mellon University.

Built with [al-folio](https://github.com/alshedivat/al-folio) (Jekyll) and deployed to GitHub Pages by `.github/workflows/deploy.yml`, which builds the site and pushes it to the `gh-pages` branch on every push to `main`.

## Where things live

- `_pages/about.md`: home page bio and research themes.
- `_bibliography/papers.bib`: publications; `selected={true}` entries appear on the home page.
- `_news/`: dated announcements shown on the home page.
- `_data/cv.yml` and `assets/pdf/Shubham_Gandhi_CV.pdf`: CV page and downloadable PDF.
- `_data/socials.yml`: contact and profile links.
- `_config.yml`: site settings.
